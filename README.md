# DynamisHelper (Ashita v4)

An optimized Dynamis tracking add-on for Ashita ported from Windower and improved , specifically tailored for the CatsEyeXI private server. It tracks obtained currency, displays the current stagger proc for your target, and provides visual ImGui overlays.

## Features
* **Native ImGui Settings Menu:** No more slash command memorization.
* **Smart Targeting:** Differentiates between static NM/Beastmen procs and time-based Nightmare procs in Dreamlands zones.
* **Currency Tracker:** Keeps a running tally of all base currency and forgotten items.
* **Stagger Timer:** Echoes your stagger count in the chat log.

## Commands
* `/dhelper config` or `/dhelper menu` - Opens the ImGui configuration panel.
* `/dhelper help` - Lists available chat commands for legacy users.
